Pertanyaan Sering Diajukan (FAQ)

Penjelasan seputar fungsionalitas dan keamanan PropMatch AI.

Apakah agen lain bisa melihat listingan milik saya?

Tidak. Setiap data diisolasi secara privat berdasarkan Uniq User ID (Nomor HP Agent). Agen A hanya dapat melihat data miliknya sendiri di dashboard.

Bagaimana cara algoritma menghitung tingkat kecocokan (Matching Score)?

Sistem menganalisis 5 parameter utama: Kesamaan Tipe/Fungsi Bangunan (30%), Toleransi Budget (30%), Kata Kunci Lokasi (20%), Jumlah Kamar Tidur (10%), dan Kamar Mandi (10%).

Apakah bisa diintegrasikan dengan n8n dan Supabase milik kami sendiri?

Sangat bisa. Struktur data aplikasi ini sudah disesuaikan dengan skema JSON standar Supabase dan REST Webhook n8n.
